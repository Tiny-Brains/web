04 / Implementation

Use the shared source.

Load design-system/tokens.css. Dark mode is the default; set data-theme="light" on the HTML element for light mode. Use var(--accent), var(--surface), and the other semantic tokens instead of copying hex values.

Use foreground or muted text on neutral surfaces. Accent text and primary button labels have dedicated colour pairs. Borders and logo colours are not body-text colours.
